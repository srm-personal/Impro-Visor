Leadsheet Studio
================

A native macOS leadsheet editor and jazz play-along engine.

Leadsheet Studio is a port of Impro-Visor (Improvisation Advisor), created by
Robert Keller and Harvey Mudd College — https://www.cs.hmc.edu/~keller/jazz/improvisor/
The accompaniment styles, grammars, chord vocabulary and the leadsheet library
ship unchanged from Impro-Visor and remain the work of their contributors.

later version. See LICENSE.txt. The complete source code is at
https://github.com/srm-personal/Impro-Visor/tree/swift-port

Install: drag "Leadsheet Studio" to the Applications folder.
