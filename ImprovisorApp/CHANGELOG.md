# Changelog

## 1.0.0

First release of Leadsheet Studio, a native macOS port of Impro-Visor.

- Notation editor with keyboard, mouse, on-screen piano and MIDI note entry;
  harmonic snapping; selection, clipboard, transposition, undo.
- Chord entry per bar with autocomplete; sections with per-section styles.
- Style-based accompaniment (145 styles), swing feel, count-in, looping,
  live tempo, mixer; built-in synth or MIDI output.
- Grammar-based solo generation into a selection or a new chorus.
- Lossless Impro-Visor `.ls` open/save; MIDI and PDF export; printing.
- Library browser over the 3,280 bundled leadsheets.
